🥫 Assistente Virtual - Gestão de Despensa (TCC)
Este documento contém as instruções para configurar o ambiente de desenvolvimento local, rodar o bot do Telegram e entender a arquitetura atual do nosso projeto.

Atualmente, o núcleo do sistema já consegue receber imagens de notas fiscais via Telegram e utilizar a API do Google Gemini (modelo 3.5 Flash Lite) para extrair e estruturar os itens em formato JSON.

1. Pré-requisitos
Antes de iniciar, certifique-se de que você tem as seguintes ferramentas instaladas na sua máquina:

Python 3.12+

Git (para versionamento de código)

PostgreSQL (para a próxima fase de persistência de dados)

Uma conta no Telegram para testar o bot.

2. Configuração do Ambiente Local
Recomendamos o uso de um ambiente virtual (venv) para isolar as dependências do projeto. Siga os passos abaixo no seu terminal (focado em ambiente Windows):

Clonar o repositório:

git clone https://github.com/SEU_USUARIO/Assistente_virtual_gestao_despensa.git
cd Assistente_virtual_gestao_despensa

Criar e ativar o ambiente virtual:

python -m venv venv
venv\Scripts\activate

Instalar as dependências:

pip install -r requirements.txt


3. Variáveis de Ambiente e Chaves de API
O projeto exige chaves de autenticação que NUNCA devem ser "comitadas" no GitHub.

Crie um arquivo chamado .env na raiz do projeto e solicite as chaves aos administradores do projeto (ou gere as suas próprias para testes isolados). O arquivo deve ter a seguinte estrutura:

# Token gerado pelo BotFather no Telegram
TELEGRAM_BOT_TOKEN=insira_o_token_aqui

# Chave gerada no Google AI Studio
GEMINI_API_KEY=insira_a_chave_aqui


4. Estrutura da Arquitetura
O código foi desenhado de forma modular para separar as responsabilidades e facilitar a manutenção em grupo.

main.py: O ponto de entrada da aplicação. Ele inicializa o bot, registra as rotas e o mantém rodando.

config.py: Responsável por carregar e validar as variáveis de ambiente (arquivo .env).

handlers.py: A camada de interface. Recebe as mensagens e fotos do Telegram e devolve as respostas formatadas ao usuário.

ai_service.py: O núcleo de inteligência. Recebe as imagens em bytes, monta o prompt rigoroso e faz a chamada para o modelo Gemini 3.5 Flash Lite, garantindo o retorno em JSON.

5. Como Executar
Com o ambiente virtual ativado e o arquivo .env configurado, basta rodar:

python main.py
O terminal exibirá a mensagem indicando que o bot está rodando. Abra o Telegram, envie o comando /start para o bot e teste o envio de uma nota fiscal.

6. Próximos Passos (Roadmap)
Nossa próxima grande etapa de desenvolvimento envolverá a modelagem do banco de dados relacional (PostgreSQL). Iremos criar as tabelas Usuario, NotaFiscal e ItemDespensa, garantindo que os dados extraídos pelo Gemini sejam armazenados, estruturados e vinculados ao ID de cada usuário do Telegram.
